# S13 迭代需求文档：多 Agent 补全 + 插件市场完善

**版本**: v1.0  
**日期**: 2026-06-13  
**基线**: `DELIVERY_STANDARD-AGENTS.md`（群聊协同）+ `DELIVERY_STANDARD-AGENTS-v2.md`（插件系统）

---

## 一、背景与问题

### 1.1 多 Agent（群聊协同）

已有后端引擎、WebSocket、前端组件，但存在阻塞上线的缺口：

| 问题 | 影响 |
|------|------|
| 群聊路由未注册 | 「群聊视图」无法访问 |
| 无取消会话 API | 长任务无法终止 |
| 用户补充未注入运行中图 | 运行中发言无效 |
| `human_review` 无处理 UI | 审核打回 3 次后流程卡死 |
| WebSocket 断线无重连 | 实时性依赖轮询 |

### 1.2 插件市场

已有 DB、API、四个前端页面骨架，但业务未闭环：

| 问题 | 影响 |
|------|------|
| 插件 Skill 执行为占位 | 安装插件无实际能力 |
| 未安装也可调用插件 Skill | 权限与隔离失效 |
| 安装无权限确认 | 不符合 PRD §5.3 |
| 无更新/配置 UI | 生命周期不完整 |
| Agent 工具列表不含 Skill | 无法选用 MCP/插件能力 |
| 列表页未合并租户启用状态 | 配置与展示不一致 |

---

## 二、本期目标（P0）

**目标**：群聊协同可端到端演示验收；插件市场完成「浏览 → 授权安装 → 配置 → 调用」闭环。

**不在本期**：PostgresSaver、进程级 Skill 隔离、插件发布到远程市场、Skill 版本回滚。

---

## 三、功能需求

### 3.1 多 Agent — 群聊协同（P0）

| ID | 需求 | 验收标准 |
|----|------|----------|
| MA-01 | 注册群聊路由 | `/workflows/:id/group-chat` 可访问，`WorkflowGroupChat` 名称一致 |
| MA-02 | 取消会话 | `POST /group-chat/sessions/{id}/cancel`；前端停止按钮；任务检测取消并标记 failed |
| MA-03 | 用户补充注入 | 运行中用户发言写入 DB，PM 节点下次执行时合并补充并广播 |
| MA-04 | 人工审核处理 | `POST /group-chat/sessions/{id}/resolve`（approve/reject）；前端审核面板 |
| MA-05 | WS 断线重连 | 断开后 3 次指数退避重连；轮询同步消息列表 |

### 3.2 插件市场（P0）

| ID | 需求 | 验收标准 |
|----|------|----------|
| PM-01 | 插件 Skill 真实执行 | 已安装插件 Skill 返回业务结构化结果（非 placeholder） |
| PM-02 | 安装门控 | 未安装/已禁用插件的 Skill 不出现在列表且 Agent 不可调用 |
| PM-03 | 安装权限确认 | 安装前弹窗展示权限列表，用户确认后安装 |
| PM-04 | 插件更新 | `POST /plugins/{id}/update` + 已安装页「更新」按钮 |
| PM-05 | 插件配置 | 已安装页「配置」对话框，调用 config API |
| PM-06 | Agent 工具含 Skill | `GET /agents/tools` 返回 native + MCP + 已安装插件 Skill |
| PM-07 | Skill 列表状态 | `list_skills` 合并 `SkillConfig` 租户启用状态 |
| PM-08 | 市场已安装标识 | 市场卡片显示已安装/禁用安装按钮 |
| PM-09 | UiAutomationTool 修复 | 补充 `parameters`，智能体对话不报错 |
