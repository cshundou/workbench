# 企业智能协作工作台 — 用户操作手册

**版本**：v1.0  
**更新日期**：2026-06-11  
**适用对象**：企业终端用户、部门管理员、租户管理员

---

## 1. 快速开始

### 1.1 访问系统

1. 在浏览器打开工作台地址（默认 `http://localhost` 或企业分配的域名）
2. 使用管理员分配的 **用户名** 和 **密码** 登录
3. 登录成功后进入 **控制台** 首页

### 1.2 首次使用 checklist

| 步骤 | 操作 | 说明 |
| ---- | ---- | ---- |
| 1 | 配置 API 密钥 | 设置 → API 密钥管理，添加 OpenAI 或兼容端点 Key |
| 2 | 创建知识库 | 知识库 → 新建，上传企业文档 |
| 3 | 等待解析完成 | 文档状态变为「已完成」后可问答 |
| 4 | 创建智能体 | 智能体 → 新建，配置提示词与工具 |
| 5 | 体验工作流 | 工作流 → 选择模板或自定义拓扑执行 |

> 未配置 LLM API Key 时，RAG 问答与 Agent 对话将提示错误码 428。

## 2. 控制台

控制台展示系统概览：知识库数量、智能体数量、工作流执行统计、Token 消耗趋势。点击卡片可跳转到对应模块。

## 3. 知识库（增强 RAG）

### 3.1 创建知识库

1. 进入 **知识库** → 点击 **新建知识库**
2. 填写名称、描述，选择公开/私有
3. 可选配置：嵌入模型、分块大小（chunk_size）、重叠长度（chunk_overlap）
4. 保存后进入知识库详情页

### 3.2 上传文档

**支持格式**：PDF、TXT、Markdown、DOCX、XLSX、PPTX、HTML

1. 在详情页 **文档管理** 区域点击 **上传** 或拖拽文件
2. 可批量上传，单文件最大 100 MB
3. 上传后状态为「解析中」，可点击 **解析进度** 查看实时进度
4. 解析完成后状态变为「已完成」，即可被检索

**URL 导入**：点击 **从 URL 导入**，输入网页地址，系统自动抓取并入库。

### 3.3 文档预览与下载

- 点击文档名称打开 **在线预览**（PDF / Word / Excel）
- 点击 **下载** 获取原始文件

### 3.4 知识库问答

1. 进入知识库 → 点击 **开始问答**
2. 在输入框输入问题，回车发送
3. 回答以 **流式** 方式逐字显示，支持 Markdown 与代码高亮
4. 回答下方展示 **引用来源**，点击可跳转原文预览
5. 切换 **知识库增强 / 纯大模型** 模式：
   - **知识库增强**：基于上传文档 RAG 检索后回答
   - **纯大模型**：不检索知识库，直接调用 LLM
6. 使用 **复制** 按钮复制回答；**重新生成** 获取新回答
7. 左侧 **会话历史** 可查看和切换历史对话

### 3.5 检索过滤

在问答或检索时，可按以下条件过滤：

| 过滤器 | 说明 |
| ------ | ---- |
| 部门 | 按文档所属部门筛选 |
| 文档类型 | PDF / DOCX 等 |
| 时间范围 | 按上传或更新日期 |

### 3.6 检索分析

知识库详情页 **检索分析** Tab 展示：

- 检索次数趋势
- 热门查询词
- 系统优化建议

### 3.7 向量库管理

在详情页 **设置** 中可：

- **增量更新**：新文档自动追加向量
- **全量重建**：重新解析并入库所有文档
- 删除文档时自动清理对应向量

## 4. 智能体（单 Agent）

### 4.1 创建与配置

1. 进入 **智能体** → **新建智能体**
2. 填写名称、描述、角色说明
3. 在 **Monaco 编辑器** 中编写系统提示词
4. 选择大模型（OpenAI / 通义 / 豆包 / MiniMax）
5. 调整参数：温度（temperature）、最大 Token、top_p
6. 启用/禁用内置工具：

| 工具 | 功能 |
| ---- | ---- |
| 知识库检索 | 查询指定知识库 |
| Tavily 搜索 | 联网搜索（需配置 Tavily Key） |
| Python 执行 | 运行 Python 代码 |
| SQL 查询 | 只读 SQL 查询（白名单表） |
| 计算器 | 数学表达式计算 |

### 4.2 对话交互

1. 进入智能体 → **开始对话**
2. 左侧 **会话栏** 管理历史会话，可新建/切换/删除
3. 对话区实时展示：
   - Agent **思考过程**
   - **工具调用** 入参与返回结果
   - 流式回答（支持 Markdown、代码高亮、复制）
4. 点击 **中断** 停止当前执行
5. 点击 **重新生成** 对最后一条回答重试

### 4.3 复制与分享

- 点击回答旁 **复制** 按钮
- 智能体可设为 **公开**，同租户其他用户可见

## 5. 工作流（LangGraph 多智能体）

### 5.1 标准五角色工作流

内置拓扑包含：

| 角色 | 职责 |
| ---- | ---- |
| 调度中心 | 任务拆解与分配 |
| 知识库 Agent | 调用 RAG 检索 |
| 搜索 Agent | Tavily 联网搜索 |
| 执行 Agent | Python / SQL 工具执行 |
| 审核 Agent | 结果汇总与审核 |

### 5.2 可视化编辑

1. 工作流 → 选择工作流 → **编辑**
2. 在 **vue-flow** 画布拖拽节点、连线
3. 配置节点参数与条件分支
4. 点击 **校验图结构** 检查 DAG 合法性
5. 保存后可执行

### 5.3 执行工作流

1. 进入 **执行** 页面
2. 输入任务描述或参数 JSON
3. 点击 **开始执行**
4. 拓扑图实时更新节点状态：等待 / 执行中 / 完成 / 失败
5. 点击节点查看 **输入输出日志**
6. 底部 **时间线** 展示全链路执行日志
7. 遇到 **人工介入** 节点时，在弹窗中确认或修改后继续
8. 点击 **终止** 中断正在运行的工作流

### 5.4 执行历史

1. 工作流 → **执行历史**
2. 查看历史实例状态、耗时、结果
3. 点击 **重跑** 以相同参数重新执行

## 6. 监控面板

进入 **监控面板** 查看：

| 模块 | 内容 |
| ---- | ---- |
| Token 消耗 | 按用户/模型/日期统计，趋势图与排行榜 |
| 接口监控 | 调用量、平均响应时间、成功率 |
| 错误日志 | 按级别、模块、时间查询 |
| 用户活跃度 | DAU / WAU / MAU |
| 系统健康 | 数据库、Redis、向量库连接状态 |

支持 **导出报表**（CSV）。

## 7. 系统设置

### 7.1 用户管理（需 `user:read` / `user:write` 权限）

- 创建、编辑、禁用、删除用户
- **批量导入/导出** 用户（CSV）
- 重置密码（须符合密码复杂度策略）
- 查看最后登录时间与 IP

### 7.2 角色管理（需 `role:read` / `role:write`）

- 自定义角色与权限分配
- 权限粒度到按钮级别
- 支持权限继承

### 7.3 API 密钥管理

- 添加 LLM / Tavily / Cohere / Pinecone 密钥
- 密钥 AES-256 加密存储，界面永不显示明文
- **测试有效性** 验证 Key 是否可用
- 设置默认模型与优先级

### 7.4 租户管理（超管，`tenant:read`）

- 创建、编辑租户
- 配置月度 Token 配额
- 租户状态启用/禁用

### 7.5 审计日志（`audit:read`）

- 查询登录、CRUD、工作流执行等关键操作
- 按操作人、时间、IP 筛选
- **导出** 审计记录

## 9. 常见问题

| 问题 | 解决方案 |
| ---- | -------- |
| 问答提示 428 | 前往设置 → API 密钥，配置 LLM Key |
| 文档一直解析中 | 联系管理员确认 arq-worker 是否运行 |
| 检索无结果 | 确认文档已解析完成；尝试调整问题关键词 |
| 登录失败 5 次 | 账号锁定 15 分钟，请稍后重试 |
| 工具调用失败 | 检查对应 API Key；查看监控面板错误日志 |
| 引用无法跳转 | 确认文档未被删除；刷新页面重试 |
