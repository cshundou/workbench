```bash

```

### 2.2 可选环境变量

```bash
export LOCUST_USERNAME=admin
export LOCUST_PASSWORD=admin123
export LOCUST_KB_ID=1
```

### 2.3 执行 Locust（100 用户）

```bash
locust -f tests/perf/locustfile.py \
  --host=http://localhost \
  --users 100 \
  --spawn-rate 10 \
  --run-time 5m \
  --headless \
  --csv=tests/perf/results/perf
```

> 输出文件：`tests/perf/results/perf_stats.csv`、`tests/perf/results/perf_failures.csv`、`tests/perf/results/perf_exceptions.csv`
